Scala CLI quick reference

The handful of commands you'll actually use. Source: Scala CLI docs.

Everyday commands

scala-cli run hello.scala
Compile and run a file (or a whole folder: scala-cli run .).
scala-cli repl
Open an interactive prompt — great for trying a snippet and seeing its type. Exit with :quit.
scala-cli test .
Run tests in the current directory (once we add any).
scala-cli compile .
Type-check and compile without running. Fast way to catch errors.
scala-cli fmt .
Auto-format your code to the standard style.
scala-cli setup-ide .
Generate the .bsp config so IntelliJ (or VSCode + Metals) can import the project.
scala-cli version
Print the installed version — the quickest "is it installed?" check.

Handy flags

--watch (or -w)
Re-run automatically on every save, e.g. scala-cli run . -w. A tight feedback loop while learning.
--scala 3.x.y
Pin a specific Scala version if you ever need to.
Mental model

One tool wraps the JVM + compiler + formatter + test runner. When you outgrow single-folder projects (much later), the same concepts map onto build tools — but you won't need one for this course.

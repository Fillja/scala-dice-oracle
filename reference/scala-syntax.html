FP in Scala · Reference

Scala syntax quick reference

Growing as we go — the syntax we've actually met. Source: Scala 3 Book.

Bindings

val x = 42
Immutable binding — can't be reassigned. The FP default; reach for this first.
var x = 42
Mutable binding — reassignable. Avoid unless you have a specific reason.

Data: the case class

case class Monster(name: String, armorClass: Int)
A product type — a bundle of named, immutable fields. The C# record.
Monster("Goblin", 15)
Construct one — no new needed.
goblin.name · goblin.armorClass
Read a field. They're vals, so read-only.
goblin.copy(armorClass = 17)
Derive a new value with some fields changed; the original is untouched.
a == b
Value equality — two case-class values are equal when their fields match.

Choices: the enum (sum type / ADT)

enum AttackResult:
  case Hit(damage: Int)
  case Miss
A sum type — a value is one of a fixed set of cases (Hit or Miss). The "OR" counterpart to a case class's "AND".
AttackResult.Hit(6) · AttackResult.Miss
Construct a case by name. Cases can carry data (Hit holds an Int) — unlike a C# enum. This is a discriminated union.

Case class + enum together = algebraic data types (ADTs): products (AND) and sums (OR), nested to model any domain.

Pattern matching: match

x match
  case Hit(dmg) => s"hit for $dmg"
  case Miss     => "miss"
Look at a value, pick the first matching case, produce its result. It's an expression — the whole match evaluates to a value (like C#'s switch expression), so you can return it or assign it.
case Hit(dmg) => …
Binds the payload: dmg is a fresh val holding the data inside that case, usable on the right of =>. This is how you read a case's data.
Exhaustiveness
Match on an enum (a fixed set of cases) and forget one → the compiler warns at compile time ("match may not be exhaustive"). A case that slips through at runtime throws a MatchError.

Collections

List(a, b, c)
Immutable, ordered sequence — the FP default. "Adding" returns a new list; the original is untouched. Singly-linked: cheap prepend and head/tail traversal, slow random access.
x +: list · list :+ x
Prepend / append. Each returns a new list — never mutates.
Vector(a, b, c)
Also immutable, but indexed — reach for it over List when you need fast random access.
Array(a, b, c)
Mutable and fixed-size — arr(0) = x rewrites a slot in place. A thin wrapper over a JVM array; use only for performance or Java interop, not everyday domain data.
xs.find(m => m.name == "Orc")
First element matching a predicate. Returns an Option: Some(x) or None.

Functions: def

def narrate(result: AttackResult): String = …
Declare a function with def. Anatomy: def keyword · narrate name · (result: AttackResult) params, written name: Type · : String return type · = … body.
vs C#: public String Narrate(AttackResult result)
Three flips from .NET: the return type comes after the params (): String), params are name: Type (inverse of C#'s Type name), and there's an = before the body — a function is defined equal to an expression.
= expression (the body)
The body is an expression whose value is the return value — no return needed. (A match, being an expression, drops straight in as a body.)
Visibility
Public by default — no keyword. Add private / protected only to restrict. (So def narrate is public.)
r => println(r)
A function value (anonymous / "lambda") — a function used as data, e.g. passed to foreach or find. Two senses of "function": a named def, and a value like this you can pass around.

Programs & strings

@main def run() = ...
Marks the program entry point (like C#'s static void Main).
s"Hello, ${who}!"
Interpolated string — like C#'s $"Hello, {who}!".
Indentation
Scala 3 uses indentation for blocks — usually no braces needed.
